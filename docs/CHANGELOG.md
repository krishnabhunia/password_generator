# What's new

## 1.0.0
- First version of Password Generator for Windows.
- Choose the elements to use, pick special characters one by one, set the length and a minimum of each element.
- Four designs to choose from in Settings; Two-pane Light is the default.
- Copy, Regenerate, strength meter and coloured characters.
- Update check at every start, with an "Update to vx.y.z" button when a newer version exists.
- Info window with the build details and the list of features.
